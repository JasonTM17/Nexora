# Observed direction characteristics

These characteristics were returned with the generated concept as an emergent
Stitch design system. They are review inputs only; this file does **not** create
the canonical `.stitch/DESIGN.md` authority.

## Visual rules

- Base: warm paper `#F6F1E8` (the returned screen token is `#FEF9F0`); elevated
  surfaces are stone `#E8E0D4`/returned `#F2EDE4`, with sand dividers.
- Ink: soft near-charcoal `#2D302B`/returned `#1D1C16`; forest `#25483B` is the
  primary action and terracotta `#B85C42` is restrained supporting emphasis.
- Type: Playfair Display is reserved for display/headline use; Inter carries
  body, UI, and small-caps labels. Runtime font loading and Vietnamese glyph
  coverage remain future validation work, not a claim from this concept.
- Geometry: softly structured 14px cards, 1px sand borders, 24px card padding,
  8px vertical rhythm, and only a faint ambient shadow. The screen is a
  2560×4720 desktop export; it is not a verified 1440px browser rendering.
- Motif: a three-layer knowledge folio presents source notes, version depth,
  and tenant boundaries as paper layers. This is intentionally unlike the
  Signal Atelier provenance rail and Luminous Grid's cool modular-card system.
- Responsive rule: Stitch describes a 4-column, 16px-margin mobile system below
  600px. The prompt requires a 375px one-column collapse, but no mobile screen
  was generated or rendered in this packet.

## Fit and follow-up questions

The result is a useful approachable alternative for public storytelling and
knowledge teams. Before selection, reviewers should test actual 375px behavior,
validate contrast and Playfair/Inter language coverage in the future product,
and ensure the soft folio metaphor remains sufficiently precise for dense
Studio workflows.
