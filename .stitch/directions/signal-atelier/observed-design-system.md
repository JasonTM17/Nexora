# Observed direction characteristics

These characteristics were returned with the generated concept as an emergent
Stitch design system. They are review inputs only; this file does **not** create
the canonical `.stitch/DESIGN.md` authority.

## Visual rules

- Base: `#F8FAFB` mineral/porcelain surface; elevated cards are white; dividers
  use a quiet neutral (`#C5C5D4` in the generated output).
- Ink: near-black `#191C1D` for readable text; deep indigo `#263C9B` provides
  action and navigation weight.
- Signal: cyan-lime `#B4F25A`/`#B6F45C` is reserved for active provenance,
  focus, and the active point in the rail—not general decoration.
- Type: Bodoni Moda for restrained editorial display use and Hanken Grotesk for
  dense UI/body labels. Vietnamese glyph coverage and runtime loading remain
  future validation work, not a claim from this concept.
- Geometry: 8px regular and 12px large functional radii, fine 1px dividers,
  no heavy shadow stack. The generated concept describes a 12-column desktop
  grid and 4-column mobile collapse.
- Motif: a vertical or horizontal rail conveys Draft → Review → Published →
  Grounded. Cyan-lime marks active state while neutral and indigo distinguish
  inactive/review states.

## Fit and follow-up questions

The result supports the intended contrast between public editorial storytelling
and a future professional Studio. Reviewers should challenge three issues before
selection: whether Bodoni Moda passes Vietnamese/performance validation, whether
the generated rail remains compact in dense Studio contexts, and whether the
subtle topology texture preserves reduced-motion and contrast expectations.
