## Direction

Signal Atelier is an editorial, precise, quietly futuristic visual direction
for Nexora. It uses porcelain/mineral surfaces, ink text, deep-indigo actions,
and a deliberately rationed cyan-lime accent. Its signature is a thin signal
rail that makes content state and provenance legible: Draft → Review →
Published → Grounded.

The generated public-home concept demonstrates the direction through:

- content-first editorial hierarchy instead of a default admin-dashboard look;
- planned/fixture/not-live labels on data-shaped regions;
- a visible provenance explanation and reduced-motion note;
- a desktop layout with a described, rather than fabricated, 375px collapse.
